Simply Swords provides fifteen standard weapon types, with additional Hammer and Dagger families used by some Unique weapons. Each trades damage, reach, or attack speed differently, and each has a matching rolled **Implicit** bonus.

## Material progression

Standard weapons are crafted in Iron, Gold, and Diamond variants using the recipes in this section. Upgrade a Diamond weapon to Netherite using the normal smithing progression.

A Netherite weapon can then become a **Runic weapon** by using a Runic Tablet as the smithing template and a Diamond as the addition. Runic weapons retain their weapon type and implicit while gaining a Runic Power.

## Weapon families

- **Chakram:** Fast circular weapon; can gain attack speed on hit.
- **Claymore:** Slow two-handed blade; can deflect incoming damage.
- **Cutlass:** Quick slashing weapon; can plunder extra loot.
- **Dagger:** Very fast blade used by several Uniques; deals increased backstab damage.
- **Glaive:** Sweeping polearm; can inflict Bleed.
- **Greataxe:** Heavy cleaver; can inflict Bleed.
- **Greathammer:** Very slow crushing weapon; sunders armour.
- **Hammer:** Compact crushing weapon used by several Uniques; sunders armour.
- **Halberd:** Heavy polearm; can inflict Bleed.
- **Katana:** Fast precision blade; can deal double damage.
- **Longsword:** Balanced sword; can deflect incoming damage.
- **Rapier:** Fast thrusting weapon; can ignore armour.
- **Sai:** Very fast blade; deals increased backstab damage.
- **Scythe:** Sweeping weapon; can execute low-health enemies.
- **Spear:** Long thrusting weapon; can ignore armour.
- **Twinblade:** Fast double-ended weapon; can gain attack speed on hit.
- **Warglaive:** Fast paired blade; can strike twice.

Weapon statistics and whether implicits are enabled are configurable. The in-game tooltip is authoritative for the current pack.
